# mod_gns3lab — модуль активности «Лаба GNS3» для Moodle 5.1

Версия 0.1.0 (alpha). Что уже есть:

- активность ставится в курс обычной формой: название, описание, эталонная лаба (`labref`), лимит сессии;
- страница активности — кнопка **«Открыть лабу на весь экран»** и встроенная схема;
- полноэкранная страница `lab.php` — схема без шапки и меню Moodle, кнопка «←» возвращает на страницу активности;
- схема — вьюер из `prototypes/topology-viewer.html`: слои L1 / L2 / L3 / OSPF, панель сведений, жесты, шторка на телефоне.

Менеджер лаб пока не подключён, поэтому любая активность показывает **демо-лабу** из `demo/`
(копии `fixtures/ospf-multi-area.*`; обновлять — `devtools/sync_demo_data.sh`).
Настройки сайта (адрес и секрет менеджера, адрес шлюза) уже есть, но пока не используются.

## Установка

**Из ZIP через интерфейс.** Соберите архив `devtools/build_zip.sh` (появится `dist/mod_gns3lab-0.1.0.zip`)
и загрузите его в «Администрирование → Плагины → Установка плагинов». Moodle проверит архив
(предупреждение про `MATURITY_ALPHA` ожидаемо) и предложит обновить базу.

**Копированием.** Положите содержимое этой папки в `public/mod/gns3lab` и откройте «Администрирование → Уведомления»
или выполните `php admin/cli/upgrade.php`.

**Для разработки** монтируйте папку в `public/mod/gns3lab` (bind mount, как в moodle-docker), а не симлинком:
страницы подключают `../../config.php` относительным путём, и встроенный сервер PHP с симлинком его не находит.

## Как проверено

На чистом Moodle 5.1.8 (PostgreSQL 16, PHP 8.3, режим разработчика):
установка, удаление и повторная установка (CLI), установка из ZIP через веб-интерфейс,
`check_database_schema` без замечаний, создание и редактирование активности формой, страница активности,
полноэкранная страница, обзор активностей курса, телефонная ширина. Ошибок JS и отладочных сообщений Moodle нет.

Проверки кода: `phpcs` со стандартами `moodle` и `moodle-extra` — чисто; `grunt amd` (ESLint Moodle + сборка) — чисто;
stylelint Moodle — чисто.

## Известные долги

- `amd/src/viewer.js` — прямой перенос прототипа. В нём отключены четыре стилевых правила ESLint
  (`curly`, `max-len`, `jsdoc/require-jsdoc`, `no-eq-null`) до разбиения на модули; остальные правила действуют.
- Строки интерфейса внутри `viewer.js` пока русские литералы; шаблон и PHP — через языковые строки (en, ru).
- Резервное копирование активности не поддерживается (`FEATURE_BACKUP_MOODLE2 = false`) — этап 4 SPEC.
- Нет external functions, менеджера, консолей — этапы 1–2 SPEC.
